키는 이 브라우저에만 저장돼요.

  1. 카카오 디벨로퍼스에서 앱을 만들고 JavaScript 키를 복사해요.
  2. 앱 설정의 플랫폼(Web)에 지금 주소 를 사이트 도메인으로 등록해요.
  3. 팀 전체가 쓰려면 js/config.local.js의 kakaoKey에 넣고 배포하면 이 화면이 뜨지 않아요.

지금은 파일로 직접 열려 있어서 카카오맵이 동작하지 않아요. 배포된 주소나 python -m http.server 8000으로 열어 주세요.
